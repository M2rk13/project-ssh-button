# Project SSH Button

Android-приложение для запуска SSH-команд плитками. Сначала выберите сервер, затем нажмите одну из его кнопок. Над кнопками находится терминальное окно с выводом команды, stderr и кодом завершения. В портретной ориентации плитки располагаются по две в ряд, в альбомной — по четыре.

Сервер хранит хост, порт, пользователя, тайм-аут и ссылку на приватный ключ. Каждая кнопка принадлежит одному серверу и хранит своё название и команду. Длительное нажатие на плитку открывает её настройку.

По умолчанию используется тёмная тема с неоновыми красными акцентами. Кнопка с символом солнца или луны рядом со списком серверов включает светлую тему с неоновыми сине-голубыми акцентами. Выбор темы сохраняется.

Приложение собирается с `compileSdk` и `targetSdk` 36 для Android 16. Минимальная версия Android — 8.0.

## Установка debug APK

После сборки файл находится по адресу `app/build/outputs/apk/debug/app-debug.apk`. Для передачи его можно скопировать в корень проекта под именем `Project-SSH-Button.apk`.

Установите файл на устройство вручную, разрешив установку приложений для выбранного файлового менеджера, или подключите устройство по USB и выполните:

```bash
adb install -r Project-SSH-Button.apk
```

Debug APK подписан отладочным ключом. Для публикации требуется отдельная release-подпись.

## Первый сервер и кнопки

1. Откройте приложение и нажмите «+ Сервер». Заполните название, DNS-имя или IP-адрес сервера, порт, пользователя и тайм-аут.
2. Нажмите «Выбрать» в поле приватного ключа. Системный выбор файлов предоставляет приложению постоянный доступ только к выбранному файлу. Приложение сохраняет URI этого файла, а не путь и не содержимое ключа.
3. Сохраните сервер, выберите его в выпадающем списке и нажмите «+ Кнопка».
4. Укажите название плитки и SSH-команду. Нажатие на плитку выполняет её команду и выводит результат в терминальное окно.

Сохранённые профили из ранней версии автоматически преобразуются в серверы и кнопки при первом запуске. Профили с одинаковым хостом, портом, пользователем и ключом объединяются в один сервер.

Если приватный ключ защищён паролем, приложение запросит его перед подключением. Пароль не сохраняется в профиле и очищается после выполнения команды.

## Первый контакт с сервером

При первом запуске приложение получает публичный ключ сервера и показывает его SHA256-отпечаток. Сверьте значение с данными администратора сервера или получите его на самом сервере:

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256
```

Если значение совпало, выберите «Доверять и запустить». Приложение закрепит ключ за профилем и при следующих запусках проверит его автоматически. При изменении ключа подключение будет заблокировано. Если сервер использует другой ключ хоста, попросите администратора указать его публичный файл, например `ssh_host_rsa_key.pub`.

Проверка ключа происходит до аутентификации пользователя. Не подтверждайте отпечаток, который получен только из непроверенного сетевого ответа.

## Сборка

Требуются JDK 17 или новее, Android SDK Platform 36 и Android SDK Build-Tools 36.x. Задайте путь к SDK через `ANDROID_HOME` либо создайте локальный файл `local.properties`:

```properties
sdk.dir=/absolute/path/to/Android/Sdk
```

Соберите debug APK из корня проекта:

```bash
./gradlew assembleDebug
```

Зависимости включают `mwiede JSch 2.28.8` и Bouncy Castle для поддержки современных ключей, включая Ed25519.

## Ограничения выполнения

Один запуск выполняет одну команду. Для защиты памяти размер приватного ключа и общий объём stdout/stderr ограничены 1 MiB. Тайм-аут ограничен диапазоном от 1 до 300 секунд.
